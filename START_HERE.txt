🚀 QUICK START (Choose One):

OPTION 1: RUN THE WEB APP (Recommended - Interactive Dashboard)
──────────────────────────────────────────────────────────────

  1. Double-click: RUN_WEBAPP.sh
     OR from terminal:
     
     ./RUN_WEBAPP.sh

  2. Open browser to: http://localhost:5000

  3. See BDIFF 2025 data, upload your own CSV, calculate impacts!

OPTION 2: RUN ANALYSIS REPORT (Batch Processing)
────────────────────────────────────────────────

  source venv/bin/activate
  python3 generate_impact_report.py

  Outputs full national analysis to console + CSV results

OPTION 3: USE PYTHON DIRECTLY (Programmatic)
─────────────────────────────────────────────

  from wildfire_impact_calculator import WildfireImpactCalculator
  
  calc = WildfireImpactCalculator('Incendies.csv')
  impact = calc.calculate_impact(x_minutes_saved=15, dept='06')
  print(f"Hectares saved: {impact['risk_adjusted_ha_saved']:.1f}")

❓ COMMON QUESTIONS:

Q: Can I use my own fire dataset?
A: Yes! Upload a CSV file in the web app. It auto-detects format.

Q: What CSV format do I need?
A: Just need an area column (any of: surface, area, ha, hectares, m²).
   Other columns (department, vegetation, cause) are optional.

Q: Does this work on Windows?
A: Yes, but paths may need adjustment. Linux/Mac work perfectly.

Q: Can I integrate this into my own application?
A: Yes! The calculation engine is a reusable Python class.

Q: How accurate is the model?
A: Calibrated using 21,141 real fire records. IPCC standard methods.

Q: Can I modify the vegetation types or regions?
A: Yes! Edit wildfire_impact_calculator.py (SPREAD_RATES, FUEL_CHARACTERISTICS)

Q: How do I deploy to production?
A: Use gunicorn. See WEBAPP_GUIDE.md for details.

🐛 TROUBLESHOOTING:

Problem: "Port 5000 already in use"
Solution: Kill existing: pkill -f "python3 app.py"
          Or use different port: python3 app.py --port 5001

Problem: "ModuleNotFoundError: No module named 'flask'"
Solution: pip install -r requirements-webapp.txt

Problem: CSV upload fails
Solution: Check it's .csv format, has area column, uses ;/,/tab delimiter

Problem: Results show but no chart
Solution: JavaScript error - check browser console (F12)

Problem: "venv not found"
Solution: Already created. If missing: python3 -m venv venv
