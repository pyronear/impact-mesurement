🎯 THE THREE USAGE PATHS (from GETTING_STARTED.md)
═══════════════════════════════════════════════════════════════════════════════

OPTION 1: WEB APP (Recommended)
────────────────────────────────
Best for: Non-technical users, interactive exploration

Quick start (60 seconds):
  1. Double-click RUN_WEBAPP.sh  OR  python3 app.py
  2. Open http://localhost:5000
  3. See BDIFF data, adjust parameters, calculate impacts!

Features:
  • View dataset statistics
  • Upload custom CSV
  • Adjust 6 parameters (wind, humidity, detection time, etc.)
  • See results in 6 metrics cards
  • Scenario comparison
  • Export as CSV


OPTION 2: BATCH REPORT (Automation)
────────────────────────────────────
Best for: Full analysis, batch processing, integration

Quick start (2 minutes):
  1. source venv/bin/activate
  2. python3 generate_impact_report.py
  3. Read console output + check wildfire_impact_results.csv

Generates:
  • National analysis overview
  • Regional risk classification
  • Impact projections
  • Sensitivity analysis
  • CSV results table


OPTION 3: PYTHON API (Integration)
──────────────────────────────────
Best for: Developers, system integration, custom analysis

Quick start (5 minutes):

  from wildfire_impact_calculator import WildfireImpactCalculator
  
  calc = WildfireImpactCalculator('Incendies.csv')
  
  # Single calculation
  impact = calc.calculate_impact(
      x_minutes_saved=15,
      t0_response_time=45,
      wind_speed_kmh=35,
      dept='06',
      vegetation_type='garrigue_maquis'
  )
  
  # Scenario comparison
  results = calc.scenario_analysis(
      minutes_saved_list=[5, 10, 15, 20, 30],
      dept='06'
  )
