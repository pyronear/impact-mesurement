🔧 PYTHON USAGE EXAMPLE:

from wildfire_impact_calculator import WildfireImpactCalculator

calc = WildfireImpactCalculator('Incendies.csv')

# Single impact calculation
impact = calc.calculate_impact(
    x_minutes_saved=15,
    t0_response_time=45,
    wind_speed_kmh=35,
    dept='06',
    vegetation_type='garrigue_maquis'
)

print(f"Hectares saved: {impact['risk_adjusted_ha_saved']:.1f}")
print(f"Value protected: €{impact['economic_value_avoided_euros']:,.0f}")

# Scenario comparison
results = calc.scenario_analysis(
    minutes_saved_list=[5, 10, 15, 20, 30],
    dept='13'
)
print(results)

📊 MODEL EQUATIONS:

1. FIRE SPREAD (Elliptical)
   Area(t) = (π/2) × R_flank × (R_head + R_back) × t²
   
   R_head  = Head spread rate (m/min)
   R_back  = Back spread rate (~10-15% of R_head)
   R_flank = Flank spread rate (~30-40% of R_head)

2. ESCAPE PROBABILITY (Sigmoid)
   P_escape = 1 / (1 + exp(-(Area - 3ha)))
   
   Critical threshold: 3 hectares
   Small fires easily contained below threshold
   
3. EFFECTIVE HECTARES SAVED
   ΔArea = Area(t₀) - Area(t₀ - x)  [direct]
   + ΔP_escape × Avg_Escaped_Size    [risk reduction]

4. CARBON EMISSIONS (IPCC Tier 1)
   tCO2/ha = Fuel_Load × Combustion × 0.47 × (44/12)
   
   Garrigue: ~15.5 tCO2/ha
   Pine: ~15.5 tCO2/ha  
   Mixed: ~10.2 tCO2/ha

5. ECONOMIC VALUE
   € = ΔArea × (Suppression_Cost + Asset_Value)
   
   Mediterranean: €8,500-10,500/ha
   Central France: €6,300/ha
