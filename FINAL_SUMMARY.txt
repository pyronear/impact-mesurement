📊 WHAT THE CALCULATOR DOES
═════════════════════════════════════════════════════════════════════════════

Given fire parameters → Calculates impact of early detection:

INPUT PARAMETERS:
  • Early detection time saved (5-120 minutes)
  • Standard firefighter response time
  • Weather (wind, temperature, humidity)
  • Location (French department)
  • Vegetation type

OUTPUT METRICS:
  • Hectares directly avoided
  • Risk-adjusted hectares saved (including escape prevention)
  • CO₂ emissions prevented (tCO₂)
  • Economic value protected (€)
  • Buildings protected
  • Vegetation classification

🎓 HOW TO USE (Quick Overview)
═══════════════════════════════════════════════════════════════════════════════

1. START THE APP
   └─ ./RUN_WEBAPP.sh
      Launches Flask server at http://localhost:5000

2. LOAD DASHBOARD
   └─ Browser loads page with dataset statistics
      Shows: Total fires, area burned, fire size stats

3. (OPTIONAL) UPLOAD DATA
   └─ Click "Upload CSV" to use your own fire dataset
      Auto-detects format and loads new data

4. ADJUST PARAMETERS
   └─ Set early detection time, response time, weather, location
      All with slider controls or dropdowns

5. CALCULATE IMPACT
   └─ Click "Calculate Impact" button
      Takes <1 second, displays results in 6 metric cards

6. VIEW RESULTS
   └─ See: hectares saved, CO₂ prevented, value protected, buildings saved
      Plus vegetation type and wind category

7. (OPTIONAL) COMPARE SCENARIOS
   └─ Click "Compare Scenarios"
      Shows impact for 5, 10, 15, 20, 30 minutes saved
      Displays as table and interactive chart

8. (OPTIONAL) EXPORT
   └─ Click "Download as CSV"
      Saves results for reports or further analysis
