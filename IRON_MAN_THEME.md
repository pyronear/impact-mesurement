# Iron Man Rescue Theme - Visual Design

## 🦾 Theme Overview

The Wildfire Impact Calculator has been redesigned with a subtle **Iron Man Rescue Theme** that reflects Tony Stark's advanced technology and mission-driven approach to emergency response.

## 🎨 Design Elements

### Color Palette (Arc Reactor Inspired)
- **Primary Gold**: `#d4af37` - Arc Reactor glow (represents Tony's technology and innovation)
- **Dark Red**: `#8b0000` - Iron Man suit accent (represents rescue urgency and passion)
- **Dark Background**: `#0d0d0d` - Night sky (represents the rescue environment)
- **Light Text**: `#f0f0f0` - High contrast readability

### Visual Features

#### 1. **Header Design**
- **Title**: "⚡ RESCUE MISSION: Wildfire Impact Analysis System"
- **Tagline**: "Advanced detection and rescue coordination platform"
- **Subtitle**: "Powered by Arc Reactor Intelligence"
- **Effects**: 
  - Red gradient background (suit theme)
  - Gold glow effects (Arc Reactor)
  - Glowing text animation (subtle pulse)

#### 2. **Panel Styling**
- **Dark theme** with gold borders (mimics suit panels)
- **Inset glow effects** for depth
- **Hover effects** that enhance the glow
- **Status sections**: SYSTEM STATUS, ANALYSIS ENGINE

#### 3. **Interactive Elements**
- **Buttons**: Gold with pulsing glow animation
  - Mimics Arc Reactor charging
  - Smooth hover transitions
  - Glowing shadows on click
- **Input fields**: Dark with gold accent borders
  - Arc-reactor style glow on focus
  - Subtle background glow

#### 4. **Animations**
- **Arc Pulse**: Buttons and borders have a subtle pulsing animation (like the Arc Reactor heartbeat)
- **HUD Glow**: Scanning effect on panels
- **Status Indicator**: Animated red dot (like suit system status)

### Typography
- **Font**: Segoe UI, sans-serif (clean, technical feel)
- **Headers**: Gold color with glow effect
- **Text shadows**: Subtle gold glow on important elements

## 🔧 CSS Implementation

Key CSS variables now use the Arc Reactor theme:
```css
--primary-color: #d4af37;        /* Arc Reactor Gold */
--secondary-color: #8b0000;       /* Iron Man Red */
--accent-red: #8b0000;            /* Suit Accent */
--light-bg: #1a1a1a;              /* Dark Panels */
--dark-bg: #0d0d0d;               /* Background */
--dark-text: #f0f0f0;             /* High Contrast Text */
```

## 📱 Responsive Design

- Mobile-optimized layout
- Touch-friendly buttons
- Readable on all screen sizes
- Animations disabled on low-power devices

## ♿ Accessibility

- **Color contrast**: Gold on dark = WCAG AA compliant
- **No animation on reduced-motion**: Respects user preferences
- **Keyboard navigation**: All interactive elements accessible
- **Focus states**: Clear gold glow on focused elements

## 📝 Design Philosophy

**"Technology serves rescue"**

The theme combines:
- **Advanced tech aesthetics** (dark, gold, glowing elements)
- **Emergency response urgency** (red accents, action-oriented)
- **Professional data presentation** (clean layout, clear hierarchy)
- **Subtle storytelling** (rescue mission framing)

Result: A powerful tool that feels like it's designed to save lives, backed by real-world data and Tony Stark's innovation mindset.
