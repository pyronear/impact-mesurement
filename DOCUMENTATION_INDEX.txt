💾 IF YOU WANT TO USE IT PROGRAMMATICALLY (Python)
═════════════════════════════════════════════════════════════════════════════════

1. wildfire_impact_calculator.py (Reusable class)
   
   Main Class: WildfireImpactCalculator
   
   Usage Example:
   
   from wildfire_impact_calculator import WildfireImpactCalculator
   
   # Initialize with data
   calc = WildfireImpactCalculator('Incendies.csv')
   
   # Single calculation
   impact = calc.calculate_impact(
       x_minutes_saved=15,
       t0_response_time=45,
       wind_speed_kmh=35,
       dept='06',
       vegetation_type='garrigue_maquis'
   )
   
   # Results
   print(f"Ha saved: {impact['risk_adjusted_ha_saved']}")
   print(f"Value: €{impact['economic_value_avoided_euros']}")
   
   # Scenario analysis
   df = calc.scenario_analysis(
       minutes_saved_list=[5, 10, 15, 20, 30],
       dept='13'
   )

2. generate_impact_report.py (Batch processing)
   
   Usage:
   python3 generate_impact_report.py
   
   Generates:
   • Full console report
   • CSV results file
   • National projections
   • Regional analysis
