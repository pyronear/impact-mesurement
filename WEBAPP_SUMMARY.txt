🐛 TROUBLESHOOTING:

Issue: "ModuleNotFoundError: No module named 'flask'"
Fix: pip install -r requirements-webapp.txt

Issue: Port 5000 already in use
Fix: 
  netstat -an | grep 5000  # Check what's using it
  pkill -f "python3 app.py"  # Kill existing
  python3 app.py --port 5001  # Use different port

Issue: CSV upload fails
Fix:
  • Ensure it's .csv format
  • Check for correct delimiter
  • Verify area column exists
  • Try with BDIFF sample file first

Issue: No results displayed
Fix:
  • Open browser console (F12)
  • Check for JavaScript errors
  • Verify all inputs are valid numbers
  • Try refreshing page
